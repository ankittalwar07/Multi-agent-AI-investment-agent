    How the agents work

    1. DecomposerBreaks the AI stack into 25+ layers from a seeded taxonomy and adds any missing ones.
    2. Component researchersOne agent per layer, in parallel: finds the leading suppliers with cited sources.
    3. Moat rubricPure Python, 0 to 100. Sole-source only counts with two independent domains.
    4. Investor councilNine rule-based investor lenses vote on every company.
    5. SynthesizerRanks the field and writes the cross-layer themes you see above.
